## 初始畫面那張怎麼拍到的

原本沒有收錄，理由是「點過一次『仍要執行』之後 SmartScreen 會記住，該畫面不易重現」。
但實際上它會記住的是**那一顆 exe**，而每次改版重新編譯的 hash 都不一樣 ——
**所以每次發新版，初始畫面都會再出現一次，那就是補拍的時機**（本張攝於 v1.1.1）。

現在初始與展開兩張並列。使用者看到的是初始畫面，只放展開後的圖會對不起來，
反而更難照著操作。
