| `welcome-window.png` | `install.md` | 成功啟動後跳出的使用說明視窗 |

## 為什麼沒有「初始畫面」那張

SmartScreen 未展開時只有「不要執行」一個按鈕。那張沒有收錄，因為：

- 使用者真正需要看的是「仍要執行」在哪，而那只在展開後才出現
- 點過一次「仍要執行」之後 SmartScreen 會記住，該畫面不易重現

初始狀態改用文字描述（install.md 有寫「一開始只有『不要執行』一個按鈕」）。
