打字打到一半才發現忘了切換輸入法，整句注音變成一串英文亂碼 ——
`ji394t au04` 其實是「我愛吃麵」。

這個工具會自動認出那串亂碼，在游標旁跳出候選中文，選一下就還原。

> **第一次安裝桌面版？** 執行時 Windows 會跳出藍色的「已保護您的電腦」警告，
> 那是正常的（程式沒有數位簽章憑證，並非有問題）——
> [安裝說明](https://b96093.github.io/bopomofo-garble-detector/install)有圖解怎麼通過。

## 功能

- **邊打邊偵測** —— 打成亂碼時自動跳候選窗，**永遠不會自動替換**
- **三個整句候選** —— `↑` `↓` 選、`Enter` 插入、`Esc` 忽略
- **逐字換同音字** —— 例如把「面」換成「麵」，涵蓋該讀音的完整同音字
- **事後補救** —— 選取亂碼後轉換，不限剛打的字（Chrome 版選取即浮出按鈕；桌面版按 `Ctrl+Alt+Z` 或用系統列選單）
- **標點與數字** —— 混在句中的 `？！、，。` 與數字都會原樣保留
- **打反容錯** —— `ㄐㄣㄧ` 會依注音結構歸位成 `ㄐㄧㄣ`，與注音輸入法行為一致
- **不誤判** —— 真英文、電話號碼、日期都不會觸發

支援標準（大千）注音鍵盤佈局。

## 安裝

### Chrome 擴充

**[前往 Chrome 線上應用程式商店安裝](https://chromewebstore.google.com/detail/gjghbjnkbbccdhfiddmceijjkebajilm)** ← 建議用這個

> 附件裡的 `bopomofo-garble-detector-chrome.zip` 是給想手動載入或檢視原始碼的人，
> 一般使用者用商店版就好。

### 桌面版

1. 下載並解壓 `bopomofo-garble-detector-desktop.zip`
2. 執行 `注音亂碼偵測.exe`
3. 首次啟動載入詞庫約 5～8 秒，完成後會跳出使用說明並建立桌面捷徑

> ⚠️ `dict.txt` 必須與 exe 放在同一個資料夾，不要只把 exe 搬出來。

## 防毒軟體可能誤判

Windows Defender 可能把桌面版 exe 判定為威脅並擋下執行。**這是誤判**，成因是
AutoHotkey 編譯檔結構像加殼、全域鍵盤 hook 像側錄器、且沒有數位簽章（本工具免費無營收）。

判定名稱中的 `!ml` 代表機器學習的啟發式猜測，不是病毒特徵碼命中。

**請不要因為作者說是誤判就相信** —— 這個工具會看到你打的每一個字，你應該多疑。
可自行驗證的方式：

- 原始碼全部公開，搜尋整個專案不會找到任何網路請求的程式碼
- 自行編譯：安裝 AutoHotkey v2 後執行 `desktop/build.ps1`
- 上傳到 [VirusTotal](https://www.virustotal.com/) 檢查
- 或乾脆不用 exe，直接執行 `desktop/app.ahk`（原始腳本不會被擋）
