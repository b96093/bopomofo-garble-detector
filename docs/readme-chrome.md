# 注音亂碼偵測 — Chrome 擴充

打字忘了切換輸入法、把整句注音打成英文亂碼時（例如 `ji394t au04`），本 Chrome 擴充會**自動偵測**、在游標旁**跳出候選中文**（3 整句候選 + 逐字換同音字），選一下就還原成你原本想打的字。

- 支援：標準（大千）注音鍵盤佈局。
- 適用：網頁輸入框、textarea、以及 Facebook 留言框之類的 contenteditable 富文字框。
- 純前端、離線可用、零外部相依。

## 安裝

**[前往 Chrome 線上應用程式商店安裝](https://chromewebstore.google.com/detail/gjghbjnkbbccdhfiddmceijjkebajilm)**

點「加到 Chrome」即可，會自動更新。安裝完成後會開啟一份使用說明，
裡面附一個可以直接打字試的示範框。

之後想重看說明：擴充功能頁 →「詳細資料」→「擴充功能選項」→ 點「重看使用說明」。

## 使用方式

在網頁輸入框打字，若打成注音亂碼會自動在游標旁跳出候選窗。全程可用鍵盤，分三區：

| 你在哪一區 | 可按 |
| --- | --- |
| 整句候選 | `↑` `↓` 換句、`↓` 到底再按一次進入逐字區、`Enter` 插入 |
| 逐字 | `←` `→` 選字（自動跳過標點與數字）、`↓` 展開同音字、`↑` 回候選區 |
| 同音字 | `←` `→` 挑字、`Enter` 換上、`↑` 收起 |

浮窗底部會顯示目前這一區能按什麼。也可以直接用滑鼠點字（例如把「面」點成「麵」）。
`Esc` 或點畫面別處＝忽略 —— **永不自動替換，一定要你確認**。

### 事後補救：選取那段亂碼

自動偵測只看游標正前方那一段。如果你已經接著打了別的字（例如中途切成英打插入英文單字、
或已經打了中文），前面那段亂碼就不會再自動跳出來 —— 這時候：

> **用滑鼠選取那段亂碼**，旁邊會浮出一個小按鈕，上面直接預覽轉換結果（例如「→ 我想說」），
> **點一下**就打開候選窗，選完替換。

不必記快捷鍵。按鈕**只在選取內容確實判定為亂碼時才出現**，平常選字複製完全不受打擾。
習慣鍵盤的話，`Ctrl+Alt+Z` 也有同樣效果。

只要是可編輯的輸入框，任何時候打的亂碼都能這樣修。手動觸發代表你已表明意圖，
判定門檻會放寬（單一個字也能轉）。

### 混在句子裡的標點與數字

不必先把標點刪掉，整句一次轉換即可：

```
su35 2l4a8 ?ji394su3        →  你知道嗎?我愛你
ji3u/ e9 3wu0 ... 2wu0      →  我應該3天不洗頭?還是2天
```

- **標點**：半形 `? ! : " ' ( )` 與全形 `、，。？！；：「」（）…` 等，原樣保留。
- **數字**：`3` `4` `6` `7` 與空白鍵在注音是聲調鍵、`1` `2` `5` `8` `9` `0` 是注音符號；
  本工具會依上下文判斷該當聲調、注音、還是你真的要打的數字／空格（0–9 皆可）。

### 限制

擴充功能只能在**一般網頁**上運作。Chrome 的**新分頁**與**網址列**是瀏覽器內建介面，
基於安全考量禁止任何擴充存取 —— 這是平台限制，非本工具可解。

## 設定

擴充功能頁點「詳細資料 → 擴充功能選項」，可調整：

- **啟用/停用偵測**
- **靈敏度**：保守（預設，幾乎不打擾）／積極（抓好抓滿）

變更後重新整理正在編輯的網頁即可生效。
