# 拍攝腳本 — 一支手機・一個演員

45 秒直式短影音（Reels / Shorts / TikTok / Threads），1080×1920。

配套文件：[video-plan.md](video-plan.md)（產品脈絡、已驗證字串、不要做的事）

---

## 前提

| 項目 | 說明 |
| --- | --- |
| 人力 | 1 人（自己拍自己，只需要手入鏡，臉可有可無） |
| 器材 | 手機 ×1、電腦 ×1、能墊高手機的東西（腳架或一疊書） |
| 錄製 | UI 畫面走**螢幕錄影**，手機只負責拍「人」的兩顆鏡頭 |
| 情境 | 告白 · LINE 電腦版 |

**為什麼 UI 不用手機翻拍**：手機拍 LCD 會產生摩爾紋與掃描條紋，文字邊緣糊掉。
全片唯一的魔法時刻（候選窗跳出）必須清晰。螢幕錄影不需要額外器材或人手。

Windows 內建：`Win + Alt + R`（Xbox Game Bar）。要更好的控制就裝 OBS（免費）。

---

## 一、拍攝前置（做完再開錄，這段省不得）

### 電腦端

- [ ] **關閉所有通知** — Windows 專注模式開啟、LINE 其他對話設靜音。跳出一則真的訊息就要重拍
- [ ] **桌布換純色**（深灰或米白），工作列設自動隱藏
- [ ] **LINE 對話對象改備註名為假名**（例：小雨）。不要出現真人姓名或大頭貼
- [ ] **LINE 字體調到「大」**（設定 → 基本設定 → 字體大小）
- [ ] **把 LINE 視窗拉成直長條**，寬約螢幕的 1/3 —— 這樣螢幕錄影裁成 9:16 時不會損失內容
- [ ] Chrome 開**無痕視窗**（避免書籤列、帳號頭像入鏡）
- [ ] Word 字級設 **30pt**
- [ ] 工具已安裝並確認可運作

### 手機端

- [ ] **直式**、4K 或 1080p、**60fps**
- [ ] 鎖定曝光與對焦（長按畫面）——中途變焦會很明顯
- [ ] 關閉自動 HDR

### 一個人怎麼按錄影又演

按下錄影 → 走回座位 → 深呼吸兩秒 → 開始演 → 演完停三秒再起身。
頭尾多錄的部分後製剪掉。每顆鏡頭至少拍三次，選最好的。

## 二、機位（只有兩個，拍攝時分兩批完成）

**A 位｜螢幕錄影** — 不需要手機。所有 UI 畫面。
**B 位｜手機・過肩** — 手機立在座位後方偏右，構圖：畫面上半是螢幕與手，下半留給字幕。只拍到手和肩膀，臉不入鏡也成立。

## 五、拍攝順序（建議）

一次擺好一個機位再拍完該機位所有鏡頭，不要來回換。

1. **先拍 B 位**（鏡 2）—— 只有一顆，架好手機拍三到五次
2. **收起手機，改用螢幕錄影**，依序錄鏡 1、3、5、6、7、8、9
3. 鏡 5 是全片核心，單獨多錄幾次，挑候選窗跳出最順的那次
4. 標題卡後製做，不用拍

---

## 六、後製要點

- 全片 **1080×1920**、30fps、H.264、`+faststart`
- 螢幕錄影是橫式，裁成 9:16 時**以 LINE 視窗為中心**（所以前置才要把視窗拉成直長條）
- 字幕放**下三分之一但避開底部 420px**（IG 的留言與按鈕會蓋住）
- 音量標準化到 −14 LUFS
- 配樂選低調的，**不要蓋過打字聲** —— 鍵盤聲本身就是節奏

---

## 七、不要做（沿用 video-plan.md）

- ❌ 不要旁白解說功能
- ❌ **不要在開頭放 logo 或片頭**
- ❌ 不要用密碼欄或登入頁當示範
- ❌ 不要出現真人姓名、真實好友清單、真實帳號

## 八、備案：改走職場路線

若要換成職場（受眾廣但情緒弱），只需改鏡 1–6 的平台：
LINE 電腦版 → **線上會議聊天框**（Teams／Meet）。
同音字示範改用 `su3rup wu0 eji42k6cl3a8 `（你今天過得好嗎，結尾有半形空格），
一樣含「你」，不需要重新驗證字串。

其餘分鏡、機位、拍攝流程完全不動。
