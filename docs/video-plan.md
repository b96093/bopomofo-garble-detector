這份文件是要交給另一個負責寫腳本的對話用的。閱讀者沒有本專案的任何背景，
因此前半段是必要的產品脈絡，後半段才是拍攝素材與已完成的內容。

## 一、產品是什麼

**注音亂碼偵測** —— 台灣注音使用者忘了切換輸入法時，把打出來的英文亂碼還原成中文。

```
ji35p 2k7cp3vu3cj0 su3     →     我真的很喜歡你
```

原理：注音鍵盤（大千佈局）上每個英文鍵都對應一個注音符號。忘了切輸入法時，
使用者其實已經「打對」了整句注音，只是顯示成英文。工具把它解回去。

### 兩個版本

| | Chrome 擴充 | Windows 桌面版 |
| --- | --- | --- |
| 範圍 | Chrome 裡的所有網頁 | Word、PowerPoint、LINE、記事本等所有程式 |
| 型態 | 未上架前需開發人員模式載入 | 免安裝 exe |

### 功能（依行銷價值排序，非依開發順序）

1. **邊打邊偵測** —— 打成亂碼時候選窗自動跳出，**永遠不會自動替換**，一定要使用者按 Enter
2. **事後補救** —— 選取任何一段已經打好的亂碼即可轉換（見下方「最被低估的功能」）
3. **逐字換同音字** —— 例如「你 → 妳」，涵蓋該讀音的完整同音字
4. **標點與數字原樣保留** —— 句中的「9點」「？」「、」不會被吃掉
5. **打反容錯** —— ㄐㄣㄧ 會歸位成 ㄐㄧㄣ，與注音輸入法本身行為一致
6. **不誤判** —— 真正的英文、電話號碼、日期不會觸發

### 隱私（是賣點，不是附註）

- 完全離線，程式碼中沒有任何網路請求
- 輸入內容只存在記憶體，用完即丟，不寫檔
- **密碼欄位刻意不處理**（`type="password"` 不在白名單內）
- 開源，MIT 授權

## 二、⚠️ 最重要的一件事：示範字串必須先驗證

影片裡打的每一串亂碼，都必須事先用引擎跑過，確認**轉出來的第一順位就是原句**。

實測發現：隨手想的句子**大約一半會失敗**——轉出來是同音的其他詞。
例如「我想跟你說一件事」的首選是「我想跟**妳**說一件事」，
「這件事我想了很久」會變成「這**見識**我想了很久」。

**不要自行發明新的示範字串。** 若需要新句子，必須回到原專案用引擎驗證後才能用。

### 已驗證可用的字串（首選即原句）

| 打出來的亂碼 | 轉換結果 | 適合的場景 |
| --- | --- | --- |
| `ji35p 2k7cp3vu3cj0 su3` | 我真的很喜歡你 | 告白／情緒最強 |
| `ji3u3ru/ 2l4x.6vu84xk7` | 我已經到樓下了 | 急事／時間敏感 |
| `au/6wu0 yl3g;392u03d9 cjo31j4ul t62l4` | 明天早上9點開會不要遲到 | 職場／**含數字，可展示數字保留** |
| `ji3dk3u3fu/3ru83a8 ` | 我可以請假嗎 | 職場／對長官 |
| `ji3e; e; y94a;61j4cl3u4n ` | 我剛剛在忙不好意思 | 日常 |
| `su3rup wu0 eji42k6cl3a8 ` | 你今天過得好嗎 | 溫暖向 |
| `rup wu0 5p 2k7cp3vu,4vu,4su3` | 今天真的很謝謝你 | 溫暖向 |
| `ji32/3u vu84ru.42l41j4ul g/ fu4` | 我等一下就到不要生氣 | 情境喜劇 |

> 注意：部分字串結尾有一個**半形空格**（一聲），複製時不要漏掉。

### 特別好用的一組

`ji35p 2k7cp3vu3cj0 su3` → 我真的很喜歡你

它的第二候選是「我真的很喜歡**妳**」，因此可以**自然地示範「逐字換同音字」**——
而且你/妳的差別在告白情境裡是有意義的，比示範「面/麵」更有感。

## 三、已完成的 45 秒腳本（初稿）

格式：直式短影音（Reels / Shorts / TikTok / Threads）

| 時間 | 畫面 | 字幕 | 備註 |
| --- | --- | --- | --- |
| 0:00–0:04 | LINE／IG 私訊輸入框特寫，正在打 `ji35p 2k7cp3vu3cj0 su3` | 無 | **不要旁白。** 用注音的人 0.5 秒內就有生理反應 |
| 0:04–0:09 | 游標停在句尾閃爍 1 秒（尷尬沉默）→ 全選刪除 | 「鼓起勇氣打了一句話」→「輸入法沒切」 | |
| 0:09–0:22 | 重打同一串，**候選窗自動跳出**，停 1 秒，按 Enter | 「現在不用重打了」 | **這格要慢。**唯一的魔法時刻 |
| 0:22–0:32 | 按 ↓ 進逐字區 → 選「你」→ 展開同音字 → 點「妳」 | 「連你/妳都能換」 | 差異化功能 |
| 0:32–0:40 | 快切三段各約 1.5 秒：Word（用含數字那句）／Google 搜尋框／Facebook 留言框 | 「Chrome 擴充 ＋ Windows 桌面版」 | Word 那句刻意含數字 |
| 0:40–0:45 | 標題卡 | 「注音亂碼偵測」「免費・開源・不連網」 | |

### 拍攝要點

**要做**
- 螢幕錄影用高幀率，候選窗跳出的動畫要順
- 字級放大（Word 用 30pt）
- 候選窗跳出後**停滿 1 秒**再按 Enter
- 直式構圖：輸入框放畫面上半部，下半部留給字幕

**不要做**
- 不要加旁白解說功能（45 秒塞不下，畫面本身已說完）
- **不要在開頭放 logo 或片頭**（前 3 秒放品牌等於自殺）
- 不要用密碼欄或登入頁當示範（與隱私訴求自相矛盾）

## 四、使用情境腦力激盪

### 使用者原本提出的兩個

1. **傳訊息給長官直接按 Enter** —— 亂碼送出去，對方秒讀，收回很尷尬
2. **打了一長串（文章／論文段落）抬頭發現全是亂碼** —— 重打時已經忘記原本寫了什麼

> 第 2 點的關鍵洞察：**重打的成本不是打字，是那段話已經想不起來了。**

### 補充的情境

**A. 不可撤回／公開場合**（痛感最強）
- 直播聊天室、線上會議聊天框 —— 按 Enter 全場都看到，沒有收回鍵
- Google 表單、線上報名、履歷表單 —— 送出就不能改
- 公開評論（商品評價、Google Maps）—— 會被搜尋到並長期留存
- 客服對話 —— 對方是陌生人，連解釋都尷尬
- 群組比一對一更慘：收回會留下「收回了一則訊息」的痕跡，反而更多人注意到

**B. 最被低估的觸發點：從密碼欄跳出來**
```
輸入密碼（英文）→ Enter 登入 → 直接開始打中文
```
輸入法還停在英文。這是每天都在發生、但沒人意識到的固定觸發點。

同類還有：切換程式後輸入法被重置（Windows 的「讓每個應用程式使用不同輸入法」）、
玩全螢幕遊戲切出來、遠端桌面／虛擬機輸入法狀態不同步。

> **行銷角度：這些不是使用者粗心，是系統行為造成的。**
> 訴求應該是「這不是你的錯」，而不是「你很健忘」。

**C. 眼睛不在螢幕上**
- 看著紙本／文獻打字（抄資料、輸入問卷）
- 聽打（會議記錄、上課筆記、逐字稿）
- 盲打的人

> 最反直覺的一點：**打字越快的人災情越慘。**手速 80 字的人一分鐘可以毀掉一整段。

**D. 搜尋框**
Google／YouTube／購物網站——按 Enter 直接跳頁，要退回重打。

## 五、核心訴求的建議

目前腳本的訴求是「幫你修好」。建議考慮改成：

> **「不用中斷。」**

真正的成本不是重打那幾秒，而是**思緒被打斷**。寫論文寫到一半發現全是亂碼，
損失的是當下的思路。

這也解釋了為什麼「**事後補救**」（反白轉換）可能才是最值錢的功能——
你可以先把話寫完，等一下再回頭修，完全不打斷正在想的事。
目前腳本把它放在第三順位，值得重新評估。
