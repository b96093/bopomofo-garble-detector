# 選取轉換支援整段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓選取轉換能一次還原一整段多行亂碼筆記，而不是只救得了一句話。

**Architecture:** 新增純函式 `DetectBlock` 到 `engine.ahk`，按換行切段、逐行呼叫既有的 `Detect`、非亂碼的行原樣保留。`CheckSelection` 依「含換行」或「候選會被版面裁掉」兩個條件路由：一句走現況的候選窗精修路徑，一段走新的「icon → Enter → 直接整段替換」路徑。候選窗版面與打字偵測路徑完全不動。

**Tech Stack:** AutoHotkey v2（`engine.ahk` / `app.ahk` / `draw.ahk`）、PowerShell 執行測試、Python 靜態檢查（`check-globals.py`）

**設計文件：** [2026-09-28-選取轉換支援整段-design.md](../specs/2026-09-28-選取轉換支援整段-design.md)

- [ ] **Step 3: 實作 `DetectBlock`**

在 `desktop/engine.ahk` **檔案最後**追加：

```ahk
; ---------- 整段轉換 ----------
; 選取一整段筆記時用。Detect 只吃單行（IsRunChar 不收換行，一碰到就整串放棄），
; 所以這裡按行切開、逐行丟進 Detect，再用原本的換行字元組回去。
;
; 不是亂碼的行原樣保留 —— 真實筆記必然中英混雜，忘記切輸入法之前打的那幾行
; 是中文，不能被動到。空行、縮排也一併保留。
;
; 參數 0.5 / 1 / manual 與 CheckSelection 的單行路徑相同：使用者已經明確說
; 「轉這一段」，再拿打字路徑那套嚴格門檻懷疑他就只是幫倒忙。
;
; 回傳 {text, hits, total, preview}；一行都沒命中就回傳空字串。
DetectBlock(text, dict) {
    ; 記住原本的換行字元，組回去時不要把 CRLF 換成 LF —— 那會改變使用者的文件
    eol := InStr(text, "`r`n") ? "`r`n" : "`n"
    lines := StrSplit(StrReplace(text, "`r`n", "`n"), "`n")

    out := [], hits := 0, preview := ""
    for ln in lines {
        body := Trim(ln, " `t")
        if (body == "") {
            out.Push(ln)
            continue
        }
        res := Detect(body, dict, 0.5, 1, true)
        if (res == "") {
            out.Push(ln)
            continue
        }
        hits += 1
        if (preview == "")
            preview := res.candidates[1]
        ; 只換中間那段，前後的空白（縮排、行尾空格）原樣接回去
        at := InStr(ln, body)
        out.Push(SubStr(ln, 1, at - 1) . res.candidates[1] . SubStr(ln, at + StrLen(body)))
    }
    if (hits == 0)
        return ""

    joined := ""
    for i, s in out
        joined .= (i > 1 ? eol : "") . s
    return {text: joined, hits: hits, total: lines.Length, preview: preview}
}
```

### Task 2: 量出候選窗放得下幾個字

設計文件說 `SINGLE_MAX` 要量不要猜。`BuildLayout` 的寬度是 `24 + 字數 × 22`（邏輯像素），上限寫死在 `DPX(700)`。這一題可以直接用程式碼問出答案。

**Files:**
- Create: `desktop/measure-candmax.ahk`

- [ ] **Step 1: 寫量測腳本**

建立 `desktop/measure-candmax.ahk`：

```ahk
#Requires AutoHotkey v2.0
; 量出候選窗在不被裁切的前提下放得下幾個中文字。
; BuildLayout 把寬度上限寫死在 DPX(700)，超過就會被裁掉 ——
; 使用者看到的是半句話，而且完全沒有提示。
;   用法（PowerShell）：
;     & "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" desktop\measure-candmax.ahk
#Include draw.ahk

GdipInit()
OUT := "字數`t候選窗寬度`t是否觸頂`r`n"
capped := 0
Loop 50 {
    n := A_Index
    s := ""
    Loop n
        s .= "字"
    view := {cands: [s], ci: 1, si: 1, zone: "sent", draft: StrSplit(s), draftText: s}
    lay := BuildLayout(view, (*) => [])
    hit := (lay.w >= DPX(700) + DPX(LY.pad) * 2)
    if (hit && capped == 0)
        capped := n
    OUT .= n . "`t" . lay.w . "`t" . (hit ? "是" : "否") . "`r`n"
}
OUT .= "`r`n第一個觸頂的字數：" . capped . "`r`n"
OUT .= "建議 SINGLE_MAX = " . (capped - 1) . "`r`n"
p := A_Temp . "/candmax.txt"
try FileDelete(p)
FileAppend(OUT, p, "UTF-8")
ExitApp()
```

- [ ] **Step 2: 改寫 `CheckSelection`**

把 `desktop/app.ahk:610` 起的整個 `CheckSelection` 函式替換成：

```ahk
CheckSelection(fromMouse := true) {
    global SELRES, SELFROMMOUSE
    if (!READY || BUSY || PAUSED || POPUP_ON || IsExcludedApp() || !CanShowOverlay())
        return
    SELFROMMOUSE := fromMouse
    text := Trim(NormalizeTyped(GetSelectedText()), " `t`r`n")
    if (text == "" || StrLen(text) > BLOCK_MAX) {
        HideIcon()
        return
    }

    ; 一句與一段走不同的路：
    ;   一句 → 候選窗精修（三個候選、逐字換同音字）
    ;   一段 → icon 顯示行數，按 Enter 直接整段替換
    ;
    ; 判斷條件有兩個。含換行是顯而易見的那個；另一個是「候選長到會被版面裁掉」——
    ; BuildLayout 的寬度上限是 DPX(700)，超過 SINGLE_MAX 個字的候選會被切掉一半，
    ; 而使用者看不出來。那種長度本來就不該進候選窗。
    if (InStr(text, "`n")) {
        ShowBlockIcon(text)
        return
    }

    ; 門檻放寬（單音節也算、跳過常見英文那關）。
    ;
    ; 這裡曾經改成跟打字路徑一樣嚴格，那在「被動偵測」時代是對的 —— 當時每次拖曳、
    ; 每次雙擊都會跑到這裡，寬鬆門檻會讓版本號、IP、電話號碼統統跳出圖示。
    ; 但現在只有快捷鍵與系統列選單會呼叫，使用者已經明確說「轉這一段」，
    ; 再懷疑他就只是幫倒忙 —— 短亂碼拼得出中文卻回報「不像亂碼」，最沒道理。
    res := Detect(text, DICT, 0.5, 1, true)
    if (res == "") {
        HideIcon()
        return
    }
    if (StrLen(res.candidates[1]) > SINGLE_MAX) {
        ShowBlockIcon(text)          ; 太長，候選窗裝不下 —— 改走整段路徑
        return
    }
    SELRES := res
    ShowIcon(res.candidates[1])
}
```

- [ ] **Step 1: 新增 `ShowBlockIcon` 與 `AcceptBlock`**

在 `desktop/app.ahk` 的 `ShowIcon` 函式**後面**追加：

```ahk
; 整段路徑：icon 顯示第一行的預覽與總行數，按 Enter 直接替換，不開候選窗。
;
; 為什麼不進候選窗：那個版面是為一句話設計的 —— 三個「整段候選」沒有意義，
; 逐字同音字盤要攤開幾百個字。而且「整段都是亂碼」的當下沒什麼好挑的，
; 救回來才是重點。要挑字，事後選那一行再按一次快捷鍵就回到候選窗。
;
; 使用者按 Enter 前看不到完整結果，這違背本工具「看得到才動手」的原則。
; 接受這個代價，是因為替換後 Ctrl+Z 可以復原，不是不可逆的操作。
ShowBlockIcon(text) {
    global BLOCKRES, SELRES
    r := DetectBlock(text, DICT)
    if (r == "") {
        HideIcon()
        return
    }
    BLOCKRES := r
    SELRES := ""                      ; 兩條路互斥，避免 IconClicked 走錯邊
    ShowIcon(Fit(r.preview, 20) . "　還原 " . r.hits . " 行")
}

AcceptBlock() {
    global BLOCKRES, BUSY, BUF, HIT
    if (BLOCKRES == "")
        return
    txt := BLOCKRES.text
    BLOCKRES := ""
    HideIcon()

    BUSY := true
    IH.Stop()
    ; 選取狀態還在，直接送字就會覆蓋掉 —— 與 Accept 的 selection 模式相同，
    ; 不必退格、完全不動剪貼簿
    SendText(txt)
    Sleep(30)
    BUF := "", HIT := ""
    IH.Start()
    BUSY := false
}
```

```ahk
    OUT .= n . "`t" . StrLen(block) . "`t" . (A_TickCount - t) . "`r`n"
}
p := A_Temp . "/blockmax.txt"
try FileDelete(p)
FileAppend(OUT, p, "UTF-8")
ExitApp()
```
