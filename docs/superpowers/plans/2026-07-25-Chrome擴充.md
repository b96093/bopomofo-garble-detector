# Chrome 擴充實作計畫（計畫 3／3）

> 執行方式：**直接建置 + 瀏覽器互動測試**（非子代理）。純邏輯小片段仍寫 `node --test`；畫面/操作以實際開瀏覽器驗證。

**Goal:** 把已完成的引擎包成可安裝的 Chrome 擴充：在網頁輸入框打字時自動偵測注音亂碼、游標旁跳候選窗（3 整句候選 + 逐字換字）、點擊替換。

**架構決定：**
- **不引入打包工具**。內容腳本用**動態 import**（`import(chrome.runtime.getURL(...))`）載入 `src/engine/` 的 ES 模組，維持零相依。
- Manifest V3。擴充根目錄 = repo 根。引擎模組列為 `web_accessible_resources`。
- 權限最小化：僅 `storage`（設定用）。`<all_urls>` 內容腳本。

**新增檔案（大略）：**
- `manifest.json`
- `src/content/content.js` — 內容腳本主程式（監看、統籌）
- `src/content/extract.js` — `extractGarbleRun(text, caret)`（純邏輯，**可測**）
- `src/content/popup.js` — Shadow DOM 候選窗（3 候選 + 逐字換字）
- `src/content/replace.js` — 針對 input/textarea 與 contenteditable 的替換
- `src/options/options.html` + `options.js` — 設定頁
- `test/extract.test.js` — extractGarbleRun 單元測試

**引擎小調整：**
- 修掉 `detect` 重複呼叫 `keysToZhuyin` 的效能點（熱路徑）：`segment`/`convertCandidates` 接受預先算好的音節。

---

## 階段 1：擴充能載入（骨架）

- `manifest.json`（MV3）、`web_accessible_resources` 指向 `src/engine/*.js`。
- 極簡 `content.js`：動態 import `dict.js`/`detect.js`，載入字典，在 console 印「ready, dict size: N」。
- **驗證（瀏覽器）**：Chrome 開發人員模式載入未封裝擴充 → 開測試網頁 → console 看到 ready 與字典大小。

## 階段 2：核心迴圈（純文字框）

- `extract.js`：`extractGarbleRun(text, caret)` 找出游標前「連續的亂碼鍵字串」→ 單元測試（node）。
- 引擎效能小修（音節重用）→ 更新既有測試。
- `content.js`：監看 textarea/input 的 `input` 事件（防抖 ~200ms）→ 取游標前亂碼段 → `detect` → 有結果就在游標旁跳**極簡浮窗**（先只顯示最佳候選）→ Enter/點擊替換 → Esc 關閉。
- `replace.js`：input/textarea 版替換（設 value + 觸發 input 事件）。
- **驗證（瀏覽器）**：測試頁的 textarea 打 `ji394t au04` → 跳「我愛吃面」→ 點一下替換成功。

## 階段 3：完整候選窗 UX（方案 C）

- `popup.js`：Shadow DOM 浮窗，含
  - 上：**3 整句候選**（Enter/數字鍵/點擊）。
  - 下：**逐字換字** —— 每個字可點，展開該字讀音的**所有同音字**（`dict.get(音節)`）供挑選。
- **驗證（瀏覽器）**：`ji394t au04` → 候選窗顯示 我愛吃面／我愛吃麵／…；點「面」展開同音字選「麵」→ 就地替換。

## 階段 4：contenteditable + 設定頁 + 打包

- `replace.js` 補 contenteditable 版（模擬輸入事件），先在自製 contenteditable 測試頁驗證，再實測 Facebook 留言框。
- `src/content/*` 游標定位：input/textarea 用鏡像法、contenteditable 用 Range API。
- 設定頁：啟用/停用、保守/積極（threshold 存 `chrome.storage`）。
- 打包 zip + 撰寫安裝說明；更新進度。
- **驗證（瀏覽器）**：contenteditable 測試頁 → 真 FB 留言框。

## 測試策略
- **可自動測**：`extractGarbleRun`、引擎效能小修（node --test）。
- **需瀏覽器手動測**：浮窗跳出/定位、替換、逐字換字、contenteditable/FB、設定頁。每階段實際操作驗證。
