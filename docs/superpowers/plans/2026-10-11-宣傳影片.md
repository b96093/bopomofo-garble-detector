# 宣傳影片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 產出兩支 30 秒直式宣傳影片（課堂版、會議版），畫面上的產品介面與轉換結果都跟真的產品一致。

**Architecture:** 一頁 `scene.html` 以 `render(t)` 依時間畫出每一格；用無頭 Chrome（透過 DevTools Protocol，Node 內建 WebSocket）逐格截圖，Node 自己合成打字聲 WAV，ffmpeg 合成 MP4。影片內容（`content.js`）與候選窗版面（`popup.js`，由產品的 `BuildLayout` 實際輸出）都先用產品的引擎驗證過，畫面再由 `check.mjs` 逐時間點核對。

**Tech Stack:** HTML/CSS/JS、Node 24（內建 WebSocket、`node:vm`、`node:assert`）、Google Chrome（headless）、AutoHotkey v2（呼叫產品引擎）、ffmpeg

**設計文件：** [2026-10-11-宣傳影片-design.md](../specs/2026-10-11-宣傳影片-design.md)

## 開始之前

- AutoHotkey 一律用 **PowerShell** 執行，不要用 Git Bash（它會把 `/ErrorStdOut` 這類參數改寫成路徑，AHK 跳出卡住的對話框）。
- AHK 的錯誤會跳出**會阻塞的 GUI 對話框**。從 Node 呼叫時用 `spawnSync` 的 `timeout`；從 PowerShell 呼叫時用 `Start-Process -PassThru` + `WaitForExit` + 逾時 `Kill()`。
- AHK 變數名不分大小寫，而且 `Try`、`ln`、`log` 這些名稱被保留或是內建函式，不能拿來當變數或函式名（2026-09／10 實測踩過）。
- **不可以更動 `content.js` 裡的任何一句中文或亂碼**，除非重跑 Task 1 的驗證並通過。2026-10-11 實測：37 句候選只有 12 句能被引擎正確轉回。
- Chrome 路徑：`C:/Program Files/Google/Chrome/Application/chrome.exe`；ffmpeg 已在 PATH（`where.exe ffmpeg`）。
- 輸出放 `dist/video/`（`dist/` 不進版控）；原始碼放 `video/`。

```js
// 依按鍵時間點合成打字聲（44.1kHz、16-bit、單聲道 WAV）。
// 每一下是一段很短、快速衰減的低通雜訊，再疊一點低頻，聽起來像鍵盤而不是電子音。
// 亂數用固定種子：同樣的輸入每次產生一模一樣的檔案，重錄結果可預期。
export function keyTrack(hits, seconds = 30, rate = 44100) {
  const n = Math.round(seconds * rate);
  const buf = new Float32Array(n);
  let seed = 12345;
  const rnd = () => ((seed = (Math.imul(seed, 1103515245) + 12345) >>> 0) / 4294967296) * 2 - 1;
  for (const { t, gain } of hits) {
    const start = Math.round(t * rate);
    const len = Math.round(0.035 * rate);
    let lp = 0;
    for (let i = 0; i < len && start + i < n; i++) {
      const env = Math.exp(-i / (0.004 * rate));
      lp += 0.35 * (rnd() - lp);
      const thump = Math.sin(2 * Math.PI * 160 * i / rate) * Math.exp(-i / (0.010 * rate)) * 0.4;
      buf[start + i] += gain * (lp * env + thump);
    }
  }
  const out = Buffer.alloc(44 + n * 2);
  out.write('RIFF', 0); out.writeUInt32LE(36 + n * 2, 4); out.write('WAVE', 8);
  out.write('fmt ', 12); out.writeUInt32LE(16, 16); out.writeUInt16LE(1, 20); out.writeUInt16LE(1, 22);
  out.writeUInt32LE(rate, 24); out.writeUInt32LE(rate * 2, 28); out.writeUInt16LE(2, 32); out.writeUInt16LE(16, 34);
  out.write('data', 36); out.writeUInt32LE(n * 2, 40);
  for (let i = 0; i < n; i++) out.writeInt16LE((Math.max(-1, Math.min(1, buf[i] * 0.5)) * 32767) | 0, 44 + i * 2);
  return out;
}
```

```js
// 用無頭 Chrome 開頁面、執行 JS、截圖。只用 Node 內建功能（WebSocket、fetch），
// 不需要 npm 安裝 Puppeteer。
import { spawn } from 'node:child_process';
import { mkdtempSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { pathToFileURL } from 'node:url';

const CHROME = 'C:/Program Files/Google/Chrome/Application/chrome.exe';
const sleep = (ms) => new Promise(r => setTimeout(r, ms));

export async function openPage(htmlPath, query = '', port = 9333) {
  const profile = mkdtempSync(join(tmpdir(), 'bgd-video-'));
  const chrome = spawn(CHROME, ['--headless=new', `--remote-debugging-port=${port}`, `--user-data-dir=${profile}`,
    '--hide-scrollbars', '--force-device-scale-factor=1', '--window-size=1080,1920', 'about:blank'],
    { stdio: 'ignore' });
  let target;
  for (let i = 0; i < 75 && !target; i++) {
    try { target = (await (await fetch(`http://127.0.0.1:${port}/json/list`)).json()).find(t => t.type === 'page'); }
    catch { /* Chrome 還沒起來 */ }
    if (!target) await sleep(200);
  }
  if (!target) { chrome.kill(); throw new Error('Chrome 沒有啟動'); }

  const ws = new WebSocket(target.webSocketDebuggerUrl);
  await new Promise((res, rej) => { ws.addEventListener('open', res, { once: true }); ws.addEventListener('error', rej, { once: true }); });
  let id = 0;
  const pending = new Map(), events = [];
  ws.addEventListener('message', (e) => {
    const m = JSON.parse(e.data);
    if (m.id && pending.has(m.id)) { pending.get(m.id)(m); pending.delete(m.id); } else events.push(m);
  });
  const send = (method, params = {}) => new Promise((res, rej) => {
    const i = ++id;
    pending.set(i, (m) => m.error ? rej(new Error(`${method}：${m.error.message}`)) : res(m.result));
    ws.send(JSON.stringify({ id: i, method, params }));
  });

  await send('Page.enable');
  await send('Emulation.setDeviceMetricsOverride', { width: 1080, height: 1920, deviceScaleFactor: 1, mobile: false });
  await send('Page.navigate', { url: pathToFileURL(htmlPath).href + query });
  for (let i = 0; i < 100 && !events.some(e => e.method === 'Page.loadEventFired'); i++) await sleep(100);
```

```js
// 輸出影片：node video/render.mjs classroom|meeting
// 只輸出幾張靜態畫面檢查：node video/render.mjs classroom --stills 1,5,9,12.5
import { openPage } from './cdp.mjs';
import { keyTrack } from './sfx.mjs';
import { mkdirSync, mkdtempSync, writeFileSync, rmSync } from 'node:fs';
import { execFileSync, spawnSync } from 'node:child_process';
import { tmpdir } from 'node:os';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const here = dirname(fileURLToPath(import.meta.url));
const root = join(here, '..');
const v = process.argv[2];
if (!['classroom', 'meeting'].includes(v)) {
  console.error('用法：node video/render.mjs classroom|meeting [--stills 1,5,9]');
  process.exit(2);
}
const si = process.argv.indexOf('--stills');
const stills = si > 0 ? process.argv[si + 1].split(',').map(Number) : null;
const out = join(root, 'dist', 'video');
mkdirSync(out, { recursive: true });

const page = await openPage(join(here, 'scene.html'), `?v=${v}`);
try {
  const name = await page.evaluate(`CONTENT.${v}.name`);
  if (stills) {
    const dir = join(out, `stills-${name}`);
    mkdirSync(dir, { recursive: true });
    for (const t of stills) {
      await page.evaluate(`render(${t})`);
      writeFileSync(join(dir, `${t}.png`), await page.screenshot());
    }
    console.log('靜態畫面：', dir);
  } else {
    const FPS = 30, N = 30 * FPS;
    const frames = mkdtempSync(join(tmpdir(), 'bgd-frames-'));
    for (let i = 0; i < N; i++) {
      await page.evaluate(`render(${i / FPS})`);
      writeFileSync(join(frames, String(i).padStart(4, '0') + '.png'), await page.screenshot());
      if (i % 90 === 0) console.log(`  ${i}/${N}`);
    }
    const wav = join(frames, 'keys.wav');
    writeFileSync(wav, keyTrack(await page.evaluate('keyHits()')));
    const ffmpeg = execFileSync('where.exe', ['ffmpeg'], { encoding: 'utf8' }).split(/\r?\n/)[0].trim();
    const mp4 = join(out, `注音亂碼偵測-${name}.mp4`);
    const r = spawnSync(ffmpeg, ['-y', '-hide_banner', '-loglevel', 'error',
      '-framerate', String(FPS), '-i', join(frames, '%04d.png'), '-i', wav,
      '-c:v', 'libx264', '-preset', 'slow', '-crf', '18', '-pix_fmt', 'yuv420p',
      '-c:a', 'aac', '-b:a', '160k', '-shortest', '-movflags', '+faststart', mp4], { stdio: 'inherit' });
    rmSync(frames, { recursive: true, force: true });
    if (r.status !== 0) throw new Error('ffmpeg 失敗');
    console.log('完成：', mp4);
  }
} finally {
  page.close();
}
```
