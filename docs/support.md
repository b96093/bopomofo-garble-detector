# 聯絡與合作

這個工具是免費的，而且會一直免費。原始碼公開、MIT 授權，你可以自由使用、修改、散布。

沒有廣告、沒有追蹤、沒有進階版，**也不收贊助**——就當作做公益。

## 有幫助的話，這幾件事比給錢有用

- **回報問題** —— 這個工具刻意不做任何遙測，所以我沒有任何自動回報管道。你不說，我就永遠不知道哪裡壞了。[到 GitHub Issues 說一聲](https://github.com/b96093/bopomofo-garble-detector/issues)
- **告訴我判錯的句子** —— 遇到該偵測卻沒跳出來、或不該跳卻跳出來的，把那串英文貼給我，那是最有價值的測試資料
- **分享給會用到的人** —— 尤其是常打注音又常忘記切換輸入法的朋友
