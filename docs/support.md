# 聯絡與合作

這個工具是免費的，而且會一直免費。原始碼公開、MIT 授權，你可以自由使用、修改、散布。

沒有廣告、沒有追蹤、沒有進階版，也不收贊助。做出來就是希望有人用得上。

## 想幫忙的話，這幾件事最有價值

- **說說你的使用心得** —— 這個工具刻意不做任何遙測，所以你的回饋是我唯一的訊息來源。哪裡順手、哪裡卡卡的，都想聽。
- **分享你遇到的句子** —— 不管是該跳沒跳、還是跳了但你其實不需要，把那串英文貼給我。這是最有價值的測試資料，準確度就是這樣一點一點長起來的。
- **推薦給用得上的人** —— 常打注音又常忘記切換輸入法的朋友，應該會謝謝你。

隨時歡迎，[到 GitHub Issues 說一聲](https://github.com/b96093/bopomofo-garble-detector/issues)就好。

## 想一起做點東西嗎

如果你手邊有想做卻一直沒動工的小工具，或覺得哪個日常流程煩很久了，很歡迎找我聊聊。

不一定要多大的東西——這個工具本身也只是從「打錯字很煩」開始的。
