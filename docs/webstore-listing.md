### 摘要（上限 132 字元）

```
打字忘了切換輸入法？把 ji394t au04 這種英文亂碼一鍵還原成「我愛吃麵」。完全離線，不蒐集任何資料。
```

### 詳細說明

```
打字打到一半才發現忘了切換輸入法，整句注音變成一串英文亂碼 ——
「ji394t au04」其實是「我愛吃麵」。

這個擴充會自動認出那串亂碼，在游標旁跳出候選中文，選一下就還原。

■ 主要功能

・邊打邊偵測 —— 打成亂碼時自動跳出候選窗，永遠不會自動替換
・三個整句候選 —— 用 ↑↓ 選、Enter 插入
・逐字換同音字 —— 例如把「面」換成「麵」，涵蓋該讀音的完整同音字
・事後補救 —— 選取任何一段亂碼即可轉換，不限剛打的字
・標點與數字 —— 混在句中的？！、，。與數字都會原樣保留
・打反容錯 —— ㄐㄣㄧ 會依注音結構歸位成 ㄐㄧㄣ，與注音輸入法行為一致
・不誤判 —— 真正的英文、電話號碼、日期都不會觸發

■ 隱私

・完全離線運作，不發送任何網路請求
・你打的內容只存在記憶體，用完即丟，不寫入任何檔案
・不使用分析或追蹤服務
・開源，MIT 授權，程式碼可自行檢查

■ 支援範圍

・標準（大千）注音鍵盤佈局
・一般輸入框、textarea，以及 Facebook 留言框這類的 contenteditable 富文字框
・Chrome 的新分頁與網址列是瀏覽器內建介面，基於安全考量禁止任何擴充存取，
　這是平台限制
・Google 文件把文字繪製在 canvas 上而非 DOM，任何擴充都讀不到，因此無法支援；
　該情境請改用桌面版

■ 其他程式也想用？

Word、PowerPoint、LINE 等 Windows 程式另有桌面版，詳見專案頁面。
```

## 權限說明（審核會逐項看）

### 單一用途說明

```
偵測使用者因未切換輸入法而誤打成英文亂碼的注音，並協助還原為原本想輸入的中文。
```

### `storage` 權限的用途

```
僅用於儲存兩項使用者設定：是否啟用偵測、偵測靈敏度。
不儲存使用者輸入的任何文字內容。
```

### 在所有網站執行內容腳本的用途

```
使用者可能在任何網站的輸入框中誤打亂碼（社群網站、搜尋框、網頁郵件、
線上文件等），因此必須在所有網站上運作，無法預先限定網域。

本擴充不讀取網頁既有內容，僅讀取使用者當下正在輸入的文字，
且該文字只存在記憶體、不傳送至任何地方。
```

### 遠端程式碼

```
否。所有程式碼與注音詞庫皆內含於擴充套件中，不從外部載入任何程式碼。
```

## 商店截圖（必要）

至少 1 張，最多 5 張。尺寸須為 **1280×800** 或 **640×400**（PNG 或 JPEG）。

建議拍這四張，依序說一個完整的故事：

| # | 內容 | 怎麼拍 |
| --- | --- | --- |
| 1 | **候選窗跳出來的瞬間** | 在 Facebook 或 Google 搜尋框打 `ji394t au04`，等候選窗出現後截圖。這是最重要的一張，要讓人一眼看懂價值 |
| 2 | **逐字換同音字** | 展開某個字的同音字盤（例如「面」→「麵」）後截圖 |
| 3 | **選取轉換** | 選取一段已打好的亂碼，出現小按鈕時截圖 |
| 4 | **設定頁** | 擴充功能選項頁 |

截圖後若尺寸不符，用小畫家或任何工具縮放／裁切到 1280×800。

> 商店頁面的第一張截圖就是使用者的第一印象，值得多拍幾次挑最好的。
