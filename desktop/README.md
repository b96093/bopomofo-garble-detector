# 注音亂碼偵測 — 桌面版

打字忘了切換輸入法、把整句注音打成英文亂碼時（例如 `ji394t au04`），
本程式會**自動偵測**並在游標旁跳出候選中文，選一下就還原成你原本想打的字。

適用於 **Word、PowerPoint、LINE、記事本等所有 Windows 程式**。
（瀏覽器裡建議改用 Chrome 擴充版，體驗更好 —— 見下方「與 Chrome 擴充併用」。）

## 安裝

1. 把整個資料夾複製到任何位置（例如 `C:\注音亂碼偵測\`）
2. 雙擊 **`注音亂碼偵測.exe`**
3. 系統列（右下角）出現圖示即代表啟動成功

第一次啟動要 **5～8 秒**載入詞庫，完成後會自動跳出使用說明，裡面有個框可以直接打字試。
之後想重看：系統列圖示右鍵 →「使用說明…」。

> 資料夾內的 `dict.txt` 與 `icon.ico` 是程式運作必需，請勿刪除或改名。

## 使用方式

### 邊打邊偵測

打字時若被判定為注音亂碼，會自動在游標下方跳出候選窗：

| 區塊 | 按鍵 |
| --- | --- |
| 整句候選 | `↑` `↓` 換句、`↓` 到底再按一次進入逐字區、`Enter` 插入 |
| 逐字 | `←` `→` 選字（自動跳過標點與數字）、`↓` 展開同音字、`↑` 回候選區 |
| 同音字 | `←` `→` `↑` `↓` 選字、`Enter` 換上、`Esc` 返回 |

`Esc` 或點畫面別處＝忽略。**永不自動替換，一定要你確認。**

候選窗擋到文字時，可**按住標題列拖曳**移開（只對當下這個候選窗有效）。

### 事後補救：選取轉換

已經打完別的字、游標離開那段之後才發現打錯，可以：

**選取那段亂碼** → 按 `Ctrl+Alt+Z`（或系統列圖示右鍵 →「轉換選取的文字」）→ 開候選窗。

> 為什麼不是選取就自動跳？因為讀取選取的文字只能透過剪貼簿，自動做會一直干擾你的複製貼上。
> 所以改成你要的時候再按。

快捷鍵可在 `settings.ini` 更改（`^`=Ctrl、`!`=Alt、`+`=Shift）：

```ini
[settings]
hotkey=^!z
```

### 設定

系統列圖示**點兩下**（或右鍵 → 設定…）：

- **啟用偵測** —— 關閉後不跳出任何候選窗
- **偵測靈敏度** —— 1（很保守）～5（很積極）的滑桿，預設 4
- **在 Chrome 中也偵測** —— 見下一節
- **開機時自動啟動**
- **檢查更新** —— 開啟下載頁看有沒有新版。程式本身不連網，是用你的瀏覽器開
- **回報問題** —— 列出有助於排查的資訊，你看過再決定要不要送出，不含你打過的內容

設定存在同資料夾的 `settings.ini`。

## 與 Chrome 擴充併用

如果你**同時安裝了 Chrome 擴充版**，在 Chrome 裡兩者都會偵測、跳出兩個候選窗。
此時請到設定頁**取消勾選「在 Chrome 中也偵測」** —— Chrome 交給擴充（它能直接讀輸入框，判斷更準），其他程式交給桌面版。

只安裝桌面版的話，維持勾選即可（預設）。

## 隱私

- 輸入內容**只存在記憶體**，偵測完即丟，**永不寫入任何檔案**
- **完全不連網**
- 按下 Enter／Tab／Esc／方向鍵、點滑鼠、切換視窗都會立刻清空緩衝

⚠️ 本程式以全域方式監看鍵盤，因此**無法辨識密碼欄位**——你輸入的密碼會短暫進入記憶體緩衝（不寫檔、不外傳）。
在意的話，可於輸入密碼前從系統列選「暫停偵測」。

「選取轉換」功能需要讀取你選取的文字，Windows 只允許透過剪貼簿取得，
因此會**短暫複製一次並立刻還原**你原本的剪貼簿內容。若你安裝了剪貼簿管理工具，它可能會記錄到。

## 防毒軟體可能誤判

Windows Defender 或其他防毒軟體可能把這個 exe 當成威脅擋下。**這是誤判**，原因是：

- 它必須**監看全域鍵盤**才能在任何程式裡運作，行為上像鍵盤側錄器
- 用 AutoHotkey 編譯，結構上像加殼程式
- 沒有數位簽章（憑證要年費，本工具免費、沒有收入）

判定名稱若帶有 `!ml`，代表那是機器學習的推測，不是比對到已知的病毒。

### 自己確認，不要只聽我說

這個工具看得到你打的每一個字，你**應該**多疑：

1. **原始碼全部公開**，搜尋整個專案找不到任何網路請求
2. **上傳到 [VirusTotal](https://www.virustotal.com/)**，看幾十家防毒引擎怎麼判斷
3. **不用 exe**：安裝 [AutoHotkey v2](https://www.autohotkey.com/)，從 [GitHub](https://github.com/b96093/bopomofo-garble-detector) 下載完整原始碼，執行其中的 `desktop/app.ahk`。功能相同，也不會被防毒擋

確認之後要繼續用 exe 的話，到防毒軟體的隔離區還原檔案，並把資料夾加入排除清單。
**請你自己操作**，不要因為任何人（包括這份說明）叫你關防毒就照做。

## 移除

系統列圖示按右鍵 →「**移除本工具…**」→ 確定。
程式會刪除桌面捷徑、取消開機自動啟動、然後結束，並開啟自己所在的資料夾，
你把整個資料夾刪掉就完全移除了。

本程式**不寫入登錄檔**，設定檔（`settings.ini`）就放在同一個資料夾內。
若你已經手動刪掉資料夾，記得另外清掉這兩個捷徑：

- 桌面上的「注音亂碼偵測」捷徑
- 開機啟動捷徑：在檔案總管網址列貼上 `shell:startup`，刪掉裡面的「注音亂碼偵測」

（第二項若不刪，Windows 每次開機都會去嘗試啟動一個已經不存在的檔案。）

## 常見疑問

### 在 Word 轉換後，字型變成新細明體？

**這是 Word 的行為，不是本工具造成的。**

Word 對**任何從鍵盤輸入的中文**，一律套用「佈景主題的中文字型」（顯示為
`+本文中文字型`，繁中預設解析成新細明體），而不是你在該段文字上設定的字型。
你自己用注音打的中文也一樣會變 —— 這點已實測驗證。

**可自行驗證**：在同一行用注音正常打幾個中文字，字型一樣會跑掉。

用 `Ctrl+D` 設定「中文字型」只對**已經存在的文字**有效；之後新打的字仍會回到主題字型。

**真正的解法 —— 改佈景主題的中文字型：**

1. 切到「**設計**」索引標籤
2. 點右側的「**字型**」→ 最下方「**自訂字型…**」
3. 把「**中文字型**」區塊的「**本文字型**」設成你要的字型
4. 確定

改完之後，所有打進去的中文（不論是你自己打的還是本工具轉換的）都會是該字型。

若只想修正已經打好的文字：全選 → `Ctrl+D` → 設定「中文字型」即可。

## 已知限制

- **不支援混合縮放的多螢幕**：各螢幕縮放比例不同時，候選窗位置可能偏移
- **畫布類程式**（Canva 等）取不到文字插入點，候選窗改以「你點擊文字框的位置」定位
- **全螢幕遊戲與簡報模式會自動暫停偵測**（候選窗畫不上去），離開全螢幕後自動恢復
