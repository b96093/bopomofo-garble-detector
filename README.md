# 文字亂碼偵測

打字忘了切換輸入法、把整句注音打成英文亂碼時（例如 `ji394t au04`），本 Chrome 擴充會**自動偵測**、在游標旁**跳出候選中文**（3 整句候選 + 逐字換同音字），選一下就還原成你原本想打的字。

- 支援：標準（大千）注音鍵盤佈局。
- 適用：網頁輸入框、textarea、以及 Facebook 留言框之類的 contenteditable 富文字框。
- 純前端、離線可用、零外部相依。

## 使用方式

1. 在網頁輸入框打字，若打成注音亂碼會自動跳候選窗。
2. **↑↓** 選整句候選、**Enter** 插入。
3. 或用滑鼠**點任一個字**，展開該讀音的同音字，挑正確的字（例如把「面」換成「麵」）。
4. **Esc** 或點畫面別處＝忽略（永不自動替換）。

## 安裝（開發人員模式載入未封裝擴充）

1. Chrome 網址列輸入 `chrome://extensions`，開啟右上角「**開發人員模式**」。
2. 點「**載入未封裝項目**」，選擇本專案資料夾（含 `manifest.json` 的那層）。
3. 完成。到任一網頁輸入框打字即可測試。

> 打包版 zip 可用 `node build/package.js` 產生（輸出於 `dist/`），或直接以上面的資料夾載入。

## 設定

擴充功能頁點「詳細資料 → 擴充功能選項」，可調整：

- **啟用/停用偵測**
- **靈敏度**：保守（預設，幾乎不打擾）／積極（抓好抓滿）

變更後重新整理正在編輯的網頁即可生效。

## 開發

```bash
npm test          # 純邏輯單元測試（引擎、偵測、抓亂碼段）
node build/build-dict.js   # 由 build/data/ 原始資料重建詞庫
node build/package.js      # 打包成 dist/ 可散布的 zip
```
